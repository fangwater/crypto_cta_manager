杠杆仅在权益为正且状态正常时提供；USDT / USDC 按等值估算，币本位账户不做
USD / USDT 杠杆换算。昨日权益、今日盈亏、历史回撤与保证金尚未接入，不填造数据。
顶部只统计账户数量和数据状态，不合并账户损益或敞口。
