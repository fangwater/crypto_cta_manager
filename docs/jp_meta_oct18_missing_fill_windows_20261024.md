## 方法、覆盖和只读保护

使用每个账户当前运行的 trade_engine 环境中的凭据，签名仅在远端内存中
计算。每次都重新读取该账户现行交易 IP；`0.0.0.0` 用本机路由查询解析后
显式绑定。无代理、无默认路由 HTTP 回退，未读取或输出凭据文件。所有
交易所请求均为 GET，不下单、不撤单、不变更交易配置。

按照 [Binance Account Trade List 文档](https://developers.binance.com/docs/derivatives/usds-margined-futures/trade/rest-api/Account-Trade-List)
逐合约查询，当页满 1000 时按 trade ID 继续分页，过滤到固定当日范围并去重。
覆盖本地截至 18 日出现过的正数量合约，加当前交易所非零持仓合约；不声称
覆盖从未在本地出现、当前也为零的合约，或当天以外的新缺口。

观察前后 96 个受保护进程、35 份配置和五张起仓/绑定表哈希保持不变；Manager
