## 结论

账户总仓位回放与 Exec 当前数量相符，没有发现需要补入非零账户起仓的证据。
“系统平仓”持续显示主要是历史策略归因账与 Exec 当前分配不一致，不能把该栏
显示的空头敞口理解为当前仍有同等实盘系统仓位。

账户快照与策略分配快照四张表中，该 source 均为零行。Manager 从零回放成交，
按原始 `batch_exec:<strategy>` 分别记账；历史系统成交没有消耗具名策略的
FIFO 仓位。Exec 运行时可以重新分配策略仓位，单凭成交归属无法恢复所有这种
分配变化。缺少策略分配锚点是目前的明确事实；不能据此把运行中发生的分配变化
全部倒推成交易开始前真实存在的仓位。

系统栏位、把系统成交随意转给具名策略，或修改账户起仓来消除显示差异。
