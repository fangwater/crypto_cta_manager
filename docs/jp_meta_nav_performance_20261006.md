实际净值复用每个账户的排序成交和小时 FIFO 检查点，查询从窗口前最近的
检查点重放。同一查询共享计算结果；后台更新成交、成交角色、费率或快照后，
整体替换分析缓存。后台汇总也复用此次 FIFO 计算，手动与定时刷新串行发布。
各时间点的逐币仓位金额通过一次遍历取得，避免每个币重新遍历全部持仓。

分钟行情连续范围使用 RocksDB range scan，零散分钟去重后使用 batched
MultiGet。已解码行情和完整五分钟定价在内存共享，缺失行情不缓存为成功。

分批并行解析，随后按原归档顺序更新目标状态。历史 JSON 和断点键没有改写。

PG 仍负责目录、权限、费率和不可变起始仓位快照。实际成交仍来自 Exec
RocksDB，信号和 K 线来自 Manager RocksDB。分析使用后台一致的费率快照，
页面计算不再单独查询实际、理论费率。登录权限检查继续读 PG。
