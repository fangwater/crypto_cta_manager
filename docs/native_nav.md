# 国内期货账户净值变动

2026-11-17。本模块提供原生多空、今昨仓的起始快照和按成交回放的人民币盈亏变化。
它不把本地可用预算当作权益，不创建 PostgreSQL 订单副本，也不推断历史策略归属。

## 快照与读取

起点保存在独立 CN Manager PostgreSQL 的 `cn_futures_nav_snapshots`，仅追加且不可覆盖。
快照保存实际 source_id、执行库世代、原生证据序号和 SHA-256、柜台交易日、每个合约
多空方向的今仓／昨仓、分钟参考价和已验证乘数。没有快照时报告不可用，不假设空仓。

候选起点来自持久化的完整 `reconciled` 记录，或明确 ready 的状态记录。查询已完成而
交易因未确认结算被阻断时，仍可选择该完整查询的历史起点。页面同时显示起点实际
时刻和当前执行状态，不把旧进程或停止状态展示成柜台在线。快照证据和库存每次查询
都重新核验，来源世代替换、原证据改变、库存冲突会停止计算。

现有库需明确审核并执行 `scripts/apply_native_nav_schema.sql`。正常启动不执行 DDL；
新空库继续由 `cn_futures_web --init-db` 和当前 `migrations/schema.sql` 显式初始化。

## 成交与估值

每个账户、交易所、原生到期合约和多空 FIFO 独立。开仓增加该方向库存，平仓仅消耗
反方向库存；平今限制在相同柜台交易日，平昨限制在更早的交易日。快照的昨仓保留为
“锚点前库存”，不捏造开仓日。正向和反向持仓同时保留，不先抵消成一个净仓。

成交按原生 `received_us` 排序，用源 RocksDB key 打破相同接收时间的平局；这是回报
接收时间口径，不是补造的交易所 UTC 成交时间。仅 `normalized_trade.origin=live_report`
且原始柜台回报身份、方向、数量和价格一致的成交可作为锚点后新成交。恢复查询、
缺失来源标签或无法核定原始时刻的历史补报保留为不可用，不能按查询时刻计入新盈亏。
执行端负责标记来源；Manager 不写执行库或为旧记录补标签。

持仓按 market-replay 的已完成分钟 close 计价。盘中 provisional 分钟还必须由 provider
水位确认完成。活跃分钟缺失、跨缺口缺少停市日历依据时不沿用旧价。休市间隙仅在
交易时段能证明没有跳过活跃分钟时沿用最后一个已完成 close。分钟末 mid 和分钟内
TWAP 都不代替此口径。当前查询窗口限制在 31 天内。完整节假日／周末日历及更长
窗口缺少计价依据时返回明确的不可用原因。

窗口先回放锚点后、窗口前成交建立库存与费用前基准，窗口起点成交属于本窗口。
普通非零时长曲线从零开始，终点与 summary 一致；零时长查询保留起点成交后的终值。
全部成交和分钟先参与计算，再为展示保留端点和分桶极值下采样。

费用优先使用实际报告的 CNY 手续费，缺少时使用该账户、实际合约、成交接收时点之前
最近的费率观察；批量拉取起点观察和窗口内变更，不逐笔发 HTTP。实际和估算数量分列。
一般 Close 没有今昨分配而两种费率不同，估算保持未知。缺少费用依据时保留费用前
盈亏，费用后净值为 null，不当作零手续费。入金、出金、结算划转、资金费率和其他
账单费用不包括在这条订单盈亏曲线内。

## API

均在国内会话和 source 权限内：

- `GET /api/native/sources/{id}/nav-snapshots`：查询不可变起点。
- `POST /api/native/sources/{id}/nav-snapshots`：配置权限提交 `expected_state_us` 和 `note`；
  网络计价完成后再次检查权限，保存事实来源及参考价。
- `GET /api/native/sources/{id}/nav?start_ms=...&end_ms=...&max_points=1000`：
  返回账户／合约盈亏、费用来源计数和曲线。`ready=false` 明确表示不能完整计算。

账户数据截至最后完整账户观察或其后已验证实时成交的实际接收时间；
程序重启、心跳与尚未完成的恢复不推进财务覆盖。请求结束晚于该时刻会返回覆盖不足。
行情缺失不以成交价回填，也不暴露一条部分计价的完整净值曲线。

## 共享网页净值接口

- `GET /api/account-timeline` 使用账户原生多空及今昨 FIFO，支持组合及合约曲线。
- `GET /api/timeline` 使用明确登记的策略归因起始快照、内部调拨和经源执行证据核验
  的成交分配，支持组合、合约和策略曲线。缺少归因快照、证据链不完整或存在未分配的
  真实成交时，该区间不可用。查看需要账户和归因账本内所有策略的查看权限。
- `GET /api/account-overview/nav?sourceId=...` 从最早账户净值起始快照累计，
  在现有证据覆盖内按上海时间四小时整点生成观测点。原生实现按请求回放。

交互查询使用共享 Protobuf 契约，并接受 `sourceIds`、`startMs`、`endMs`、
`maxPoints`、`symbols` 和 `view`。金额以 CNY 计，合约数量为手数。每个已完成分钟和
实际成交均参与回放，交互曲线保留精确起止及 15 分钟展示点。浏览器请求结束晚于现有
证据时，响应返回实际结束时刻和原请求结束时刻。缺少有效起点、行情或必要手续费依据
会返回明确的不可用原因。国内期货不适用永续资金费。

## 一分钟参考净值

组合图提供 TWAP 和 VWAP 两组费前、费后参考。两组从所选区间起点的已核验净手数
出发，按 Manager 持久接收的目标批次回放账户里各具体到期合约的净目标。先按时间对齐到
首个可用的完整交易分钟，再直接使用 `baseline_1min` 中对应合约该分钟的 TWAP 或 VWAP。
同一合约同一分钟内的目标以最后一个批次为准。执行分钟尚未结束时，模拟仓位继续持有
上一目标。已发布目标指定柜台交易日时，参考分钟需属于该交易日。

模拟持仓与实际曲线使用相同的已完成分钟收盘价估值。两条费后参考都扣相同区间、同一
采样点的累计人民币手续费总额，包含有证据的实收费和费率估算。适用范围、权限和成交
证据沿用实际净值与策略目标账本。缺少闭合行情、TWAP 或 VWAP 时，对应参考显示不可用，
实际曲线及有完整价格依据的另一组参考仍可用。
