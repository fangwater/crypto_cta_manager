# 国内期货账户净值变动

2026-11-17。本模块提供原生多空、今昨仓的起始快照和按成交回放的人民币盈亏变化。
它不把本地可用预算当作权益，不创建 PostgreSQL 订单副本，也不推断历史策略归属。

## 快照与读取

起点保存在独立 CN Manager PostgreSQL 的 `cn_futures_nav_snapshots`，仅追加且不可覆盖。
快照保存 source_id、执行库世代、`trades_key`（建立时 `cn_trade_updates` 的最后 key）、
原生交易日、每个合约多空方向的今仓／昨仓、分钟参考价和已验证乘数。没有快照时报告
不可用，不假设空仓。

期初持仓由配置者明确给出（Manager 不读取柜台持仓快照），Manager 在建立时切取成交
列族的当前 key，并按建立时刻的已完成分钟收盘价计价。之后只有 key 大于 `trades_key`
的成交参与回放；每次查询核对快照属于同一 source 与执行库世代，且切点存在。

现有库需明确审核并执行 `scripts/apply_native_nav_schema.sql`。正常启动不执行 DDL；
新空库继续由 `cn_futures_web --init-db` 和当前 `migrations/schema.sql` 显式初始化。

## 成交与估值

每个账户、交易所、原生到期合约和多空 FIFO 独立。开仓增加该方向库存，平仓仅消耗
反方向库存；平今限制在相同柜台交易日，平昨限制在更早的交易日。快照的昨仓保留为
“锚点前库存”，不捏造开仓日。正向和反向持仓同时保留，不先抵消成一个净仓。

成交来自 `cn_trade_updates`，每笔交易所成交一条，按接收时间排序、记录 key 打破平局。
交易日、开平、手数和手续费取记录扩展块，不由时间戳推算：周五或节前夜盘成交属于下一
交易日，平今只匹配同一交易日开仓的库存。锚点之后入库、交易日早于锚点交易日的成交
（例如恢复补记）可能已含在期初持仓中，此时报告不可用，而不重复计入。

持仓按 market-replay 的已完成分钟 close 计价。盘中 provisional 分钟还必须由 provider
水位确认完成。活跃分钟缺失、跨缺口缺少停市日历依据时不沿用旧价。休市间隙仅在
交易时段能证明没有跳过活跃分钟时沿用最后一个已完成 close：周六、周日开始的时段不交易
（周五夜盘属于下周一交易日，照常计价）；交易日日盘收盘之后到下一交易日首根 K 线之间
不是交易时间，持仓沿用该交易日最后一个 close，因此周末和节假日净值不变动。Manager
没有交易所节假日日历：节假日只体现为某交易日收盘后没有行情；交易日内工作日时段的
缺口仍报告不可用。分钟末 mid 和分钟内
TWAP 都不代替此口径。当前查询窗口限制在 31 天内。

窗口先回放锚点后、窗口前成交建立库存与费用前基准，窗口起点成交属于本窗口。
普通非零时长曲线从零开始，终点与 summary 一致；零时长查询保留起点成交后的终值。
全部成交和分钟先参与计算，再为展示保留端点和分桶极值下采样。

费用优先使用记录中的 CNY 手续费。缺少时使用账户费率服务在成交接收时点之前的观察
估算；实际和估算数量分列。
一般 Close 没有今昨分配而两种费率不同，估算保持未知。缺少费用依据时保留费用前
盈亏，费用后净值为 null，不当作零手续费。入金、出金、结算划转、资金费率和其他
账单费用不包括在这条订单盈亏曲线内。

## API

均在国内会话和 source 权限内：

- `GET /api/native/sources/{id}/nav-snapshots`：查询不可变起点。
- `POST /api/native/sources/{id}/nav-snapshots`：配置权限提交 `trading_day`、
  `positions`（`[{venue,symbol,side,today,yesterday}]`）和 `note`；网络计价完成后再次检查
  权限，保存切点及参考价。
- `GET /api/native/sources/{id}/nav?start_ms=...&end_ms=...&max_points=1000`：
  返回账户／合约盈亏、费用来源计数和曲线。`ready=false` 明确表示不能完整计算。

账户数据截至执行记录的覆盖时刻：本机执行库为读取时刻，同步副本为已提交的导出切点。
请求结束晚于该时刻会返回覆盖不足。
行情缺失不以成交价回填，也不暴露一条部分计价的完整净值曲线。

## 共享网页净值接口

- `GET /api/account-timeline` 使用账户原生多空及今昨 FIFO，支持组合及合约曲线。
- `GET /api/timeline` 使用策略归因锚点与其后 `cn_uniform_orders` 中的策略成交份额、
  内部对冲腿，支持组合、合约和策略曲线。缺少归因锚点、执行库世代不符或记录指向名单
  外策略时，该区间不可用。查看需要账户和归因账本内所有策略的查看权限。
- `GET /api/account-overview/nav?sourceId=...` 从最早账户净值起始快照累计，
  在现有证据覆盖内按上海时间四小时整点生成观测点。原生实现按请求回放。

交互查询使用共享 Protobuf 契约，并接受 `sourceIds`、`startMs`、`endMs`、
`maxPoints`、`symbols` 和 `view`。金额以 CNY 计，合约数量为手数。每个已完成分钟和
实际成交均参与回放，交互曲线保留精确起止及 15 分钟展示点。浏览器请求结束晚于现有
证据时，响应返回实际结束时刻和原请求结束时刻。缺少有效起点、行情或必要手续费依据
会返回明确的不可用原因。国内期货不适用永续资金费。

## 参考净值

组合图显示实际费后净值和 `1min_twap`、`1min_vwap`、`5min_twap`、`5min_vwap`。
参考曲线从所选区间起点的已核验净手数出发，按 Manager 持久接收的目标批次回放各
具体到期合约的净目标。窗口从目标后的首个完整交易分钟开始，数据取该合约的
`baseline_1min`。一分钟窗口直接使用对应分钟的 TWAP 或 VWAP。五分钟 TWAP 等权平均
有成交分钟的 VWAP，五分钟 VWAP 为总成交额除以总成交手数和合约乘数。无成交分钟
仍计入窗口长度，整个窗口无成交时参考价不可用。

同一合约同一窗口使用最后一个目标批次。窗口从目标接收后的第一个交易分钟开始，允许跨休市、
收盘和交易日：Exec 常驻执行目标，收盘时刻的批次（如 ni2701 于 11-23 15:00、交易日 20261123）
在下一时段开盘执行，窗口分钟可属于之后的交易日。只有早于目标柜台交易日的分钟视为数据错误。
窗口结束时按参考价一次计入目标对应的
整数手数变动。窗口尚未结束时，模拟仓位继续持有上一目标。

模拟和实际持仓使用相同的已完成分钟收盘价估值。四条参考曲线均扣除同一采样点的累计
人民币手续费总额，手续费金额单列。适用范围、权限和成交证据沿用实际净值和策略目标
账本。缺少闭合行情或必要价格时，对应参考显示不可用，实际曲线及有完整价格依据的参考
仍可用。
