理论曲线将 source/symbol/venue 身份与市场价格序列预先关联，逐笔成交使用
索引，行情游标随时间递增。保留原 BTreeMap 的求和顺序、每次 FIFO 操作和
浮点计算，未更换 PnL 公式、成交数量、费率、初始库存或估值时间。

曲线缓存从全局目标/行情 revision 改为相关范围。历史窗口使用各隔离市场的
稳定目标前缀；较新的可变尾部仍保守失效，迟到的历史目标触发完整重建 epoch。
行情缓存保留最多 4096 页的内存变更记录；其他币种或区间的数据不再清空该
窗口，记录淘汰时保守失效。跨越窗口起点的执行计划还跟踪起点之前的定价分钟，
以便历史成交量修复正确重算期初数量。事实分钟估值缓存使用同一范围约束。
相关费率、目标或行情修复仍会失效；缺失行情仍拒绝不完整曲线。
不增加持久化派生缓存，不改变行情 HTTP 出口、权重、并发或回填行为。
