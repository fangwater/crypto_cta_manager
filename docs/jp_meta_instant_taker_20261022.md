## 缓存命中边界修复

默认查询携带秒或毫秒。K 线扫描会包含结束时间所在分钟，但完整性判断原来把
所需分钟数向下取整，导致已有完整缓存仍被当成缺失，等待同币种无关历史任务，
并可能扩展到额外 24 小时补数。在持有该币种回填锁、缓存完整的测试中，整分钟
查询正常，非整分钟查询会超时；修复后整分钟、末微秒及半分钟结束均立即命中，
没有网络请求。内部覆盖区间上界统一向上取整，再限制到当前已收盘边界，用户
请求时间和 NAV/FIFO 起止语义保持不变。

成本查询另将原有 `max(start-300s, retention_cutoff)` 过滤提前到索引的二分查找，
不再先克隆该来源全部历史 delta 后删除区间外记录。精确保留五分钟信号匹配边界，
回归测试比较整分钟及分钟内边界的完整结果，费用、方向和历史参照不变。
缓存修复通过完整 Rust 测试与 release 构建后替换 Manager；没有改变 CPU 24、
HTTP 权重/并发或专用出口，也没有新增持久化派生索引。
