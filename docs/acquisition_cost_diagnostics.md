## 币种和策略定位修复（已发布）

旧页面的币种柱形统计整个查询区间，复盘下拉菜单却只有当前页的 25 个
delta，没有跨页的币种筛选。2026-10-13 对 trade03 查询一日区间
`1791783060000–1791869460000`（毫秒）时共有 1,559 页，CTKUSDT
有 711 笔可比成交，价格成本差约 106.265 U，费后差约 100.042 U。
这些是相对理论成交的成本差，不是账户实际盈亏。此时目标索引已就绪，
没有加载警告；较差成交所在的旧目标很容易被时间分页隐藏。

发布 `20261013T060934Z` 增加“定位 delta”的币种与排序选择。点击上方柱形会筛选该币，
按价格差金额最大优先返回第一页，并自动选择最大的一条复盘。
筛选和排序在服务端分页前执行，浏览器只请求一页，不遍历下载全部页。

随后补充独立的“复盘策略”下拉框，可与币种联合选择，例如
`CTKUSDT + rbf_small`。选项来自整个查询范围的策略汇总，筛选在分页前
执行，不从当前页推断有哪些策略；切换币种或翻页保留复盘策略。
2026-10-13 只读检查线上 `strategyName=rbf_small` 的一日查询返回 256 页，
第一页 25 个目标全部属于 `rbf_small`，没有数据警告。旧版可先使用上方
“策略”输入框填写完整名称 `rbf_small`，再点“查询生成”。

API 新增 `rowSymbol`（精确合约名称，入口统一为大写）和 `rowSort`
（`latest` 或 `price_shortfall`，默认 `latest`）。返回
`row_symbol`、`row_sort`、`filtered_row_count`；页数按筛选后的目标计算。
只筛选 `rows`，不改变账户/时间/策略范围内的 totals、points 和 breakdowns。
缺少可比成交的目标排在有效价格差之后，包括有效差为负数的情况。
按排序后的原始虚拟目标索引关联成交点，不通过过滤后的行号关联。
`rowStrategy` 为精确策略名称，返回 `row_strategy`；与 `rowSymbol`
取交集。它只筛选明细，与改变整个查询范围的 `strategyName` 分开。
策略回归覆盖同币种/同发布时间下 small 与 mid 的成交隔离，以及首页全是
mid 时仍能跨页定位 small；不同币种的小策略不会被错带入 CTK 复盘。

新增 Rust 回归覆盖旧 CTK 目标被最新页隐藏、跨页筛选与排序、原始成交索引
保持对应、负成本与未知成本排序，以及空筛选/越界页。操作者随后明确授权
上线，已发布到 jp-meta；el01 保持不动。详见
[币种与策略定位发布记录](jp_meta_delta_drilldown_20261013.md)。

## 页面

- 五分钟价格、理论 TWAP 和实际 VWAP 按价格数量级及同组最小有效价差
  选择共同小数位；极小数使用科学计数法。这是展示精度，不是交易所 tick。
- 同时显示原始 `实际价格 - 理论价格` 和按买卖方向调整的 bps。
  买入更贵、卖出更便宜均为正的成本差。
- 全区间的币种图选取价格差金额绝对值最大的 12 个币，可切换 bps / U。
  延迟图展示同量虚拟成交额占比及该组价格差，可切换目标 / 订单计时。
- 当前分页内每个目标可通过下拉菜单或表格“复盘”选择。ECharts 叠加
  五个分钟价格、理论/实际均价及 Maker / Taker / 未分类 / 内部对敲成交点。
  支持原始价格 / 方向调整 bps，以及横轴缩放。
- 切换账户、时间范围或策略会取消旧查询、清除旧结果；不会将旧账户的
  查询响应挂到新账户下。

## 判断口径

这些结果是可以同时出现的观测线索，不是确定的因果分类。

| 线索 | 默认规则 | 数据限制 |
| --- | --- | --- |
| 五分钟反转 | 首分钟 → 内部转折点 → 末分钟方向相反，两段各至少 10 bps | 必须有五个实际有成交的分钟；跳过分钟和全空收盘价回退不用于判断 |
| 分钟跳变 | 相邻两分钟均价变化绝对值至少 10 bps | 不跨空白分钟连接；不能区分瞬时跳价和持续快速移动 |
| 成交延迟 | 数量加权平均目标延迟至少 60 秒，或有成交落在五分钟窗口结束及之后 | 只统计查询范围内的配对成交；需要结合算法预期执行节奏判断 |

价格形态阈值、平均延迟阈值可在复盘区调整。成交回报时间用于延迟计算；
订单计时沿用现有订单信号时间，历史缺失时以成交时间回退，可能低估订单延迟。

拆解保持以下恒等式，均使用理论价格作 bps 分母并按买卖方向调整：

```text
实际相对首个计价分钟 + 首分钟相对理论 TWAP = 实际相对理论 TWAP
```

后半项反映基准随价格路径变化的影响，前半项仍包含市场变化。
无配对成交时延迟为不可用，不展示为零延迟。完成率不等同于参考覆盖率。

## API

现有 `/api/catalog/acquisition-cost` 的每个分页 `rows[]` 增加 `execution`：

- `first_fill_ts_us` / `last_fill_ts_us`：全部配对成交的首尾时间。
- `qty_weighted_target_delay_us` / `qty_weighted_order_delay_us`：以绝对成交数量加权。
- `after_window_qty_ratio`：时间大于等于 `virtual_execution_ts_us` 的成交数量占比。
- `fills`：按成交时间排序的图表点，包含数量、价格、流动性和两种延迟。
- `fills_sampled`：超过 200 笔时抽样，保留时间首尾、价格最小/最大值及
  沿时间排序序列均匀抽取的其他点。统计始终使用全部成交，不用抽样点重算。

只为当前分页生成复盘数据，按原有虚拟目标索引关联，避免依靠币种或时间
单独拼接不同目标。原有成本金额、手续费、匹配规则和汇总口径不变。
没有新增数据库表、持久化缓存、交易接口调用或行情下载路径。
前后端按同一个 API 格式一起发布；未增加版本分支。
